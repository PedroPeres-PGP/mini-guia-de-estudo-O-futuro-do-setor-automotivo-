# mini-guia-de-estudo-O-futuro-do-setor-automotivo-
Nesse estudo analisamos o mercado automotivo em 2026, destacando a transição para carros elétricos e híbridos flex . O projeto aborda o uso de Inteligência Artificial e conectividade em veículos definidos por software , as novas exigências de segurança (ADAS)  e o forte impacto das marcas chinesas na economia e no consumo no Brasil .
